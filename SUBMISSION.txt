一、方法说明（可复制到网页）

MemoryShield+ 是自行部署的同步 Add/Search 记忆系统。原始消息及其
user_id、session、role、顺序和时间来源保存在 SQLite；使用
text-embedding-v4 的 1024 维向量，在相同 user_id 内执行精确余弦检索，
结合词项与原始消息证据召回，并可使用 qwen3-rerank 对有限候选重排。
规则、事实、状态历史、表格声明与数值记录、跨片段显式引用及长历史摘要
均按确定性方法提取或选择，返回带来源的证据；Search 不生成最终答案。
长证据按范围和预算组织，保留原文、角色与出处，并标明遗漏或不完整。
不同用户的记忆严格隔离，session 用于来源组织而非额外 Search 过滤。

本次补齐许可证、归属声明与提交/部署说明，不改 v3.14.0 检索算法，
不声明新的 Smoke 或 Full 分数。对应的历史 Smoke 分数 78.56 仅是该次冒烟
结果，不能视为 Full 能力或正式公榜成绩。实际拟参评版本必须与官网同赛道
已通过 Smoke 的版本、部署源码和配置一致，不能把另一版本算法改名为 v3.14.0。

二、接口与鉴权（不包含密钥值）

Add：https://hlq5070.tail50f4d4.ts.net/add
Search：https://hlq5070.tail50f4d4.ts.net/search
Health：https://hlq5070.tail50f4d4.ts.net/health
鉴权：沿用最初 v1 提交的原 Memory System Key，不更换其值；支持
Authorization: Bearer <Memory System Key>、Token 或 X-Api-Key。
实际密钥仅保存在私有配置及官网相应秘密字段，不放在此文档或公开源码中。
Eval/Leaderboard Key 与 Memory System Key 用途不同，二者均不公开。

固定公共入口由 Tailscale Funnel 443 转至本机共享 ingress 8282，
本次文本评测要求 legacy_key_target=textual，再转到独立 Textual 8080。
原 Key 每次只支持一个赛道；官网版本名、请求内容或 user_id 不改变本机模式。
所有 Smoke/Full 均结束后才允许切换；HTTP 暂时空闲不足以证明评测结束。
启动文本评测前检查 /__gateway_health 的有效配置、textual 目标、无待切换
且活动请求为零。Full 受理后冻结版本、代码、模型配置与文本模式直到结束。

三、模型披露

Embedding：Alibaba Cloud Model Studio/DashScope 的 text-embedding-v4，
standard 模式，1024 维，每批最多十条文本。
Reranker：qwen3-rerank；有限候选、有限并发、失败使用确定性排序回退。
生成式 LLM：Add 和 Search 均为 0 次调用，不使用其他生成模型代替规定模型。
平台负责统一 Answer/Eval。

官网正文要求开源组使用 text-embedding-v4，LLM 相关组件使用 gpt-4o-mini，
Reranker 不限；Full 勾选项另写 Add 预期使用 gpt-4o-mini。完全无生成式
LLM 方法是否需额外调用该模型，官方 issue #19 仍未明确答复。因此如实
披露本方法为 LLM-free，不将其写成已获官方认可或已确认完全满足资格。

四、容量与运行限制

建议官网初始并发：max_add_concurrency=2，Search concurrency=2，Top K=100。
2/2 是保守起步建议，不是服务器新增限流值、Full 吞吐保证或容量认证。
完整 Full 数据规模下的存储、RAM、带宽、上游额度与持续性能尚未端到端实测。
报名时应补充实际主机资源、可用时段、提供方额度及运行限制，避免把本地
合成测试结果当作正式 Full 容量证据。

当前源码默认 Embedding 并发 8、SQLite 锁等待 30 秒；重排最多 8 并发，
网络操作超时 6 秒。共享入口 I/O 超时 300 秒，连接/写入/连接池等待为
3/60/10 秒。Embedding SDK 超时未由应用显式设置。以上是配置说明，
不保证每个 Full 请求都能在有效超时内完成。上游错误不应伪报 Add 成功。

当前 Windows 主机通过用户登录后的 Startup 文件夹启动隐藏 watcher，
不是计划任务；重启后依赖该用户登录。评测期间需保持主机供电、联网与
可用。共享 gateway 要求单 worker；原文数据库与 Coding 存储保持独立。
Textual 根源码包与 ingress 独立源码包/manifest 一并说明实际部署，
公开仓库的固定提交包含两者。
